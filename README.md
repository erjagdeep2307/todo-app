# TaskPulse

TaskPulse is a modern task and todo management web app built with React, TypeScript, Vite, Tailwind CSS, Supabase, React Query, and Cloudinary.

## Features

- User authentication with Supabase
- Protected dashboard routes
- Create, view, and delete tasks
- Task priority and status tracking
- Task image upload with Cloudinary
- Dashboard task progress summary
- Responsive sidebar layout
- Toast notifications for user feedback

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router
- TanStack React Query
- Supabase
- Cloudinary
- Sonner
- Heroicons
